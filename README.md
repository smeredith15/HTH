# High Tide Handmade

Catalog of record, inventory, budgeting and craft-fair kiosk for
[High Tide Handmade](https://www.etsy.com/shop/HighTideHandmade25) — scorched
and carved wood art from the Chesapeake region.

Static site. No server, no database, no build step. See [SPEC.md](SPEC.md) for
the full specification and [DECISIONS.md](DECISIONS.md) for assumptions made
while building.

## Running it

Open `index.html` through a local web server — not by double-clicking it, as
browsers restrict storage for `file://` pages:

```
npm run serve      # python3 -m http.server 8000
```

Then visit <http://localhost:8000>. On first run the app loads the 61 pieces
from the spec's Appendix A.

## Tests

```
npm test
```

No dependencies. Node's built-in test runner, plain ES modules.

## Where the data lives

Two layers, joined by artwork `id`:

- **Private** — IndexedDB in your browser. Everything: all pieces with all
  fields, listings, sales, customers, commissions, expenses, settings. Never
  committed. **Exports are the backup of record** — Backup → Export everything.
- **Public** — `data/catalog.json` and `images/`, both committed. Only pieces
  marked public, and only their public fields. Generated by the Publish step
  (Phase 4); never edited by hand.

Print masters are never committed. The registry records where they live.

### What Phase 1 covers

Artwork CRUD, quick add, duplicate-as-new with the restricted field copy, the
IndexedDB layer, export and merge-aware import, persistent-storage request, the
last-exported warning, and the Appendix A seed import.

## Layout

```
index.html
app/
  main.js router.js
  store/     private IndexedDB layer, schema, seed data, backup
  admin/     catalog, artwork detail and edit, backup, settings
  public/    catalog loader — the kiosk imports only from here
  kiosk/     customer-facing tablet mode
  ui/        DOM helpers
styles/
data/catalog.json    generated, committed
images/<artwork-id>/ web images and thumbnails only
tests/
```

Nothing under `app/kiosk/` or `app/public/` may import `app/store/`.
`tests/kiosk-isolation.test.js` enforces it.
